# Akin

Приложение для подготовки товаров к группировке. Товары, группы и IndexedDB работают в браузере; сервер используется только для входа и прокси к OpenRouter.

## Что делает

- загружает CSV с товарами и сам называет файл по схеме `seller_title_количество_товаров_ДД.ММ.ГГГГ`; если в файле несколько разных `seller_title`, используется `all`;
- в режиме «Сначала категории» группирует товары по фото **без учёта категорий**, чтобы найти одинаковые модели в разных категориях; главный экран показывает список категорий, которые можно разворачивать и скрывать, внутри категории — карточки групп (по первому товару), внутри группы — компактные карточки товаров; на этом этапе LLM не используется;
- в режиме категорий можно выбирать группы чекбоксами, в том числе из разных категорий, и пакетно переносить их в нужную категорию; группы с разными категориями собраны в «Потребують уваги»;
- ведёт общий справочник категорий: при загрузке страницы категорий IndexedDB заполняется из `categorise.json`, категория, добавленная вручную, сохраняется для всего сервиса, а не для одного файла, и подхватывается поиск по id, по-украински и по-русски;
- экспортирует из режима категорий только изменённые товары: `id`, `goods_category_title`, `goods_category_id`;
- после разнесения по категориям переходит к обычной группировке и финальному экспорту `id`, `goods_category_title`, `goods_category_id`, `group_title`;
- обычная группировка без режима категорий остаётся доступной;
- группирует товары одной категории, у которых совпадает не менее 80% фото (от меньшего набора);
- очищает названия групп от цвета, размера и роста через OpenRouter;
- проверяет пары групп через Jev и автоматически объединяет варианты одной модели при высокой уверенности;
- показывает спорные объединения как предложения для ручной проверки;
- даёт вручную перетаскивать товары и объединять группы;
- автоматически объединяет группы с одинаковым названием внутри категории;
- не трогает группы, изменённые вручную, при повторной ИИ-обработке;
- запоминает фильтры, сортировку, размер страницы и размер карточек отдельно для каждого файла;
- выводит группы страницами: по умолчанию 50, с выбором 25/50/100/200;
- сохраняет результат в IndexedDB браузера;
- в обычной группировке экспортирует XLSX с колонками `id`, `Название`, `Категория`, `Группа`;
- при включённом «Топ продавець» предлагает цвета товарам без цвета и добавляет в XLSX колонку `Цвет` с предложенными цветами.

## Поток «Спочатку категорії»

1. Откройте раздел «Спочатку категорії» и загрузите CSV.
2. На главном экране появится список категорий. Разверните нужную
   категорию — внутри будут карточки групп по первому товару.
3. Откройте группу, чтобы увидеть все товары компактными карточками,
   сменить категорию, разделить группу или отделить неправильные товары.
4. Выбирайте группы чекбоксами, в том числе в разных категориях, и
   переносите их пакетно. Группы с разными категориями находятся в
   «Потребують уваги».
5. Нажмите «До групування»: целевые категории применятся, группы
   пересоберутся внутри уже исправленных категорий.
6. Запустите очистку названий/Jev и экспортируйте финальный XLSX.

Экспорт из раздела категорий содержит только изменённые товары. Финальный
экспорт содержит все товары с колонками `id`, `goods_category_title`,
`goods_category_id`, `group_title`. На этапе категорий LLM не используется.

## Запуск

Скопируйте `.env.example` в `.env.local` и заполните переменные:

```env
APP_PASSWORD=пароль-для-входа
APP_AUTH_SECRET=случайная-строка-32+-символа
OPENROUTER_API_KEY=ключ-openrouter
OPENROUTER_MODEL=anthropic/claude-haiku-5.5
OPENROUTER_JEV_MODEL=typesafe/jev-1.14
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

Затем:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Если `APP_PASSWORD` и `APP_AUTH_SECRET` не заданы, в development приложение
открывается без входа. В production без этих переменных приложение закрыто.

## Деплой на Vercel

Добавьте те же переменные в Vercel → Project Settings → Environment Variables
для Production, Preview и Development. GitHub Actions не нужны: Vercel
подхватывает изменения из репозитория.

Ключ OpenRouter лучше создать отдельный и с лимитом расходов. Пароль
защищает и интерфейс, и `/api/clean-titles`, `/api/group-matches`, чтобы
ключом не воспользовались посторонние.
